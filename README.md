# ハコイチ値札加工ツール

ハコイチ管理システムから出力したバーコードPDFを、ホチキス留めしやすい
余白付きの値札PDFに自動変換するツールです。ブラウザだけで完結し、
PDFはどこにも送信されません。

## 使い方

GitHub Pages を有効化すると `https://hachi-bit.github.io/hacoichi-tag-tool/` で
アクセスできます。

1. 上記URLをブラウザで開く
2. ハコイチ管理システムから出力したPDFをドラッグ＆ドロップ（またはタップして選択）
3. 必要なら「ホチキス用の余白」「タグ間のすき間」を調整
4. 「この設定で変換する」を押す
5. プレビューを確認して「加工済みPDFをダウンロード」

## 対応フォーマット

ハコイチ管理システムが出力する形式のみ（商品カードが横に並ぶレイアウト）。
カードの検出は画像処理で自動判定しているため、多少のレイアウト変更には
耐えられる想定ですが、大きく形式が変わった場合は正しく検出できないことが
あります。
